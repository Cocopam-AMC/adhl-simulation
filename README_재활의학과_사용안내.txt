ADHL Simulation - iPad/Android Web App (PWA)

[재활의학과 측 실제 사용]
1. 전달받은 웹 주소를 iPad의 Safari에서 엽니다.
2. Safari 공유 버튼 -> '홈 화면에 추가'를 선택합니다.
3. 홈 화면의 ADHL 아이콘으로 실행합니다.
4. 대상자 ID를 입력합니다.
5. 병실 또는 복도를 선택합니다.
6. 동작 사이 휴식시간(60~120초)을 한 번 설정합니다.
7. 실험 시작을 누르면 해당 구역의 동작 순서가 무작위로 생성됩니다.
8. 각 동작은 '준비 완료 / 시작' -> 3,2,1 음성 카운트다운 -> 수행 순서로 진행됩니다.
9. 시간형 동작은 시간이 끝나면 '동작이 완료되었습니다' 음성이 나옵니다.
10. 거리/횟수형 동작은 수행 후 '동작 완료' 버튼을 누릅니다.
11. 세션 종료 후 CSV 저장 버튼을 눌러 파일로 저장합니다.

[중요]
- 다음 동작은 휴식이 끝난 후에만 표시됩니다.
- 휴식시간은 랜덤이 아니라 세션 시작 시 설정한 고정값입니다.
- 동작 순서는 세션 시작 시 한 번만 무작위로 섞이고 끝까지 유지됩니다.
- CSV에는 동작 순서, 시작/종료 시각(ms/ISO), 수행시간, 목표, 휴식시간이 기록됩니다.
- 앱 데이터는 서버로 업로드하지 않습니다. CSV는 해당 기기에서 사용자가 직접 저장합니다.

[배포자(연구팀)용]
이 ZIP은 정적 웹앱입니다. HTTPS 정적 호스팅에 index.html이 루트가 되도록 업로드하세요.
예: GitHub Pages / Cloudflare Pages / Netlify.
PWA의 오프라인 캐시 및 홈 화면 설치 기능은 HTTPS 환경에서 정상 동작합니다.
로컬 파일(index.html 직접 열기) 방식은 iPad에서 권장하지 않습니다.

[아이패드 TTS]
iPad Safari의 보안 정책 때문에 음성은 사용자가 버튼을 누른 이후에 재생되는 구조로 구현했습니다.
소리가 나지 않으면 iPad 미디어 음량과 무음/집중모드를 확인하세요.
